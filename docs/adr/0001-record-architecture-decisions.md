# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-31

## Context

Decisions about the layers and their contract need a durable, reviewable record that contributors and agents can
rely on.

## Decision

Significant decisions are recorded as short ADRs in `docs/adr/`, numbered in sequence. An accepted ADR is not edited
in substance; a new one supersedes it.

## Consequences

- One place per decision; other documents link here instead of restating it.
- Records are public and licensed CC-BY-SA-4.0 like the rest of the documentation.
